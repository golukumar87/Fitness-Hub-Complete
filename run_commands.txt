# How to run the RAJ Fitness Gym project
# File: run_commands.txt
# OS: Windows 11 (PowerShell/CMD compatible)

============================================================
A) RUN ONLY THE FRONTEND (recommended for demo)
============================================================
1) Start a simple local server (avoids file:// security issues and enables PWA).

From project root:
  cd "c:/Users/Ravish Kumar/Desktop/codeing/RAJ Project/GYM WEBSITE"

Then run one of the following:

Option 1 (uses npm package 'serve'):
  npx serve -l 5500

Open in browser:
  http://localhost:5500

Option 2 (Node built-in; no extra install):
  npx http-server -p 5500
  (If http-server is not installed yet, install globally or use npx after install)

Notes:
- If you open index.html directly via file://... you may see errors due to origin/security restrictions.
- If the console shows missing images like default-avatar.png, add the file into:
    /images/default-avatar.png
  or update HTML/JS to point to an existing avatar.

============================================================
B) RUN BACKEND (Node/Express + MongoDB) + SERVE FRONTEND
============================================================
This project includes an Express backend in:
  raj-gym-backend/

The backend also serves the frontend folder (GYM WEBSITE) automatically.

1) Open a terminal and go to backend folder:
  cd "c:/Users/Ravish Kumar/Desktop/codeing/RAJ Project/GYM WEBSITE/raj-gym-backend"

2) Install dependencies:
  npm i

3) Create/edit .env (must exist in raj-gym-backend/ directory):
  - MONGODB_URI= "your MongoDB Atlas connection string"
  - JWT_SECRET= "some long random secret"
  - CORS_ORIGIN= "http://127.0.0.1:5500"  (or your frontend port)

4) Start backend:
  npm start

Backend URL:
  http://localhost:4000

After backend is running, open the site via:
  http://localhost:4000

============================================================
C) DEVELOPMENT MODE (backend with auto-restart)
============================================================
From:
  cd "c:/Users/Ravish Kumar/Desktop/codeing/RAJ Project/GYM WEBSITE/raj-gym-backend"

Run:
  npm run dev

Open:
  http://localhost:4000

============================================================
D) IMPORTANT PORT / CORS COMPATIBILITY
============================================================
- Frontend local server used above typically runs on: 5500
- Backend runs on: 4000
- If you run backend separately from frontend, ensure CORS_ORIGIN matches frontend URL.

Example:
  CORS_ORIGIN=http://127.0.0.1:5500

============================================================
E) BACKEND HEALTH CHECK
============================================================
If backend is running, verify:
  http://localhost:4000/health

Should return:
  { "ok": true }
